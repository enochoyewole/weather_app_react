Weather App React

A weather application built with react and vite that bhelps users check the weather conditions and forecasts for selcted locations.

Features
-Search for locations and view waether information.
-Use browser geolocation when permission is granted.
-View current conditions and available hourly and daily forecasts.
-Switch between supported weather measurement units.
-Display loading and error states.

Technologies 

-React
-Javascript
-Vite 
-Axios
-open-Meteo weather API
-OpenStreetMap Nominatim for location search

Prerequisites
Install Node.js and use the package manager that matched the project's lockfile

Getting started
Clone the repository

  git clone https://github.com/enochoyewole/weather_app_react.git
  cd weather_app_react

Install dependencies using the package manager configured for the project.

For a project using package-lock.json:
 npm ci
  
start the development server:
  npm run server  


Available scripts
-npm run dev -start the development server
-npm run build -create a production build
-npm run preview -preview the production build

Weather App React 

A responsive weather application built with React and Vite. It lets users look up locations and view weather conditions and forecasts.

Features
-Search for a location and view its weather.
-Use browser geolocationto get local weather, when permission is granted.
-View current conditions, hourly forecasts, and daily forecasts.
-Switch supported temperature, wind-speed, and precipitation units.
-View loading and error states while weather data is retrieved.

Tech stack
-React
-Vite
-Javascript
-Axios
-Open-Mateo weather API
-OpenStreetMap Nominatimfor location search

Prerequisites
Install Node.js before setting up the project. Use the package manager that matches the project's lockfile.

Getting Started 
Clone the repository:
git clone https://github.com/enochoyewole/weather_app_react.git

install dependencies using the package manager configured for the project.

For npm projects with a package-lock.json:
  npm ci

start the development server:
  npm run 
open  the local address displayed in the terminal.
